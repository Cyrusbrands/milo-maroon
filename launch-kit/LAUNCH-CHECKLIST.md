- Publish the reviewed repository as Cyrusbrands/milo-maroon.
- Publish v0.15.1 as a prerelease, including Windows, USB Offline and Models ZIPs and SHA256SUMS.txt.
- Verify each README image, download and model-fetch URL on the public site.
- Add About description and relevant topics. Optionally upload social-preview.png as the repository social preview.
- Play the actual application and compare it with the captures; do not replace real results with idealized concept art.
- Keep original code, generated-art and recording licenses distinct. Missing Pixabay per-file provenance stays documented.
- After the repository/downloads are live, post the X draft with the short clip. Confirm platform rules before posting elsewhere.
- Use real feedback and steady releases to grow the project. Stars and reach cannot be guaranteed.
