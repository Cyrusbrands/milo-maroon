# Roadmap

These are directions, not delivery-date promises.

- Improve grip, walking/resting transitions, prop alignment and body clearance.
- Polish shoreline entry, underwater readability, foam and surface wildlife.
- Expand deterministic regression coverage and refactor the layered activity system.
- Develop longer friendships, linked inventions and small persistent consequences.
- Add context-aware wildlife interactions and supported facial controls.
- Review accessibility, reduced motion, adaptive quality and performance.
- Complete audio provenance and add subtle sound variation.
- Improve reproducible releases, multi-monitor support and code signing if feasible.
- Welcome community-written stories and replaceable original assets.

Keep the island patient. A contribution does not need to be spectacular to belong here.
